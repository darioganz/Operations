# Operations Repository

## Overview
This repository contains key projects developed for the **Smart Contracts Lab**, including:  
- **Onboarding Chatbot**: A **Telegram-based assistant** that streamlines onboarding for new students at the University of Zurich. Automates FAQs, document distribution, and real-time communication with the onboarding team.  
- **Custom Coding Exercises**: A curated set of **hands-on smart contract exercises** designed to upskill new lab members in Solidity and blockchain development.  

## Key Features
- **Chatbot** – Automates onboarding, registration, and communication via Telegram.  
- **Blockchain Education** – Smart contract exercises covering key DeFi and NFT concepts.  
- **Crypto Tooling** – Includes a **Crypto Price Alert Script** for tracking real-time market movements.  

## Technologies
- **Python** (Telegram Bot, Crypto Alerts)  
- **Solidity** (Smart Contracts)  
- **JavaScript & Web3** (For blockchain interaction)  

## Why This Matters
- **Bridging AI & Blockchain** – Practical applications that improve user experience and **automate complex workflows** in the Web3 space.
